# BeamNG Info Config Generator v1.3.0

## BeamNG 0.40 and RLS 2.8

- **RLS Contracts** supports RLS Career Overhaul 2.8, which moved its files to a new layout. RLS 2.7 keeps working; the addon detects which version is installed.
- Field choices follow BeamNG 0.40 stock vehicles, for example Induction `NA`/`Turbo`/`SC` and Fuel `Battery` for electric vehicles. **Analyze** points out older values such as `Natural`. Existing files are never rewritten silently.
- New fields: insurance class, years, region, population, and default paint.

## New

- **From stock** fills price, power, torque, weight, years, and more from the stock vehicle a mod is based on. The game is found through Steam, or can be chosen in Settings. Generation and Fix can use the same data.
- Generate and Fix show a preview of every file and changed field before writing, can be limited to what search and filters show, and offer backups.
- Redesigned interface: compact grouped form, status chips, problem counts per mod, a vehicle-selector style Preview, notifications, and a start screen with the detected mods folder.
- Optional Russian interface in Settings.

RLS 2.8.0 was checked against its public source with the same isolated Lua tests as 2.7.2; the Patreon alpha package may differ and then shows a warning. Not tested in-game. See [RLS compatibility](https://github.com/Holorigg/beamng-info-config-generator/blob/v1.3.0/docs/RLS_CONTRACTS.md).
