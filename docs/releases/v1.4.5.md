# BeamNG Info Config Generator v1.4.5

## Faster saving in ZIP mods

- Saving a configuration inside a ZIP mod no longer rebuilds the archive in the default **Automatic** mode. The changed file is written at the end and the archive's file list points to it, so a 460 MB mod that took about 22 seconds now saves in a fraction of a second. The old copy stays inside the archive, a few KB each time; checked inside BeamNG.drive 0.40.5 that the game reads the new version.
- **Disk** and **RAM** rebuild a clean archive without recompressing it, so they are much faster too.
- The progress bar follows the archive being rebuilt, by size, instead of counting configurations.

## Update notice

- At startup the app checks GitHub once for a newer release and shows a bar with **Download** (opens the release page) and **Skip this version**. Nothing is downloaded or installed. Turn it off in Settings, or check manually in **About**.
