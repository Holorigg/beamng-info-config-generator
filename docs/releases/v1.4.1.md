# BeamNG Info Config Generator v1.4.1

## RLS Contracts

- Fixed the addon setting its unload mode too late, which the game warned could unload it. Click **Apply patch** again to update an installed addon.
- Checked with the **RLS Career Overhaul 2.8.0** release inside BeamNG.drive 0.40.4: in a started career, an added model appeared in the live Drift and Drag pools and the Race filter stayed in effect. Playing an actual contract was not tested. See [RLS compatibility](https://github.com/Holorigg/beamng-info-config-generator/blob/v1.4.1/docs/RLS_CONTRACTS.md).
