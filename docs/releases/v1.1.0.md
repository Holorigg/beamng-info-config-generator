# BeamNG Info Config Generator v1.1.0

**Release date: 2026-10-15**

Since v1.0.4, this release substantially updates the desktop workspace and strengthens how configuration metadata is reviewed and written.

## Highlights

- Find configurations with search and missing/incomplete/valid status filters. Switch between tree and sortable table views, select multiple configurations, and work in Details, JSON, or Preview tabs.
- Save form edits without losing other metadata such as display names, years, paints, statistics, or mod-specific fields. Unsaved drafts are protected when switching configurations, rescanning, or closing.
- Generate missing metadata, repair incomplete records, analyze issues, and inspect operation history with progress, cancellation, actual success counts, and JSON export.
- Scan ZIP and extracted mods, including common `repo` and `unpacked` containers; symlink/junction cycles no longer cause repeated scanning. Thumbnails load on selection to avoid reading all image data during scans.
- Choose Automatic, Disk, or RAM ZIP writes and enable optional dated backups in Settings.
- Use the About dialog for Holorigg attribution, project and issue links, and bundled license notices. The app now has a generated application icon and offline SVG interface icons.

## Metadata And Storage Notes

The validity indicator checks required metadata fields; it does not verify that a configuration will appear at a dealership in-game. Part-name-based vehicle detection is heuristic, and the application does not measure or calculate performance figures.

Ordinary saves retain fields not edited in the form. Explicit regeneration replaces the entire info document after confirmation. Relaxed JSON syntax and legacy encodings can be read, but saved documents use standard JSON and do not retain comments or original formatting.

ZIP replacements are built in a temporary file beside the original and need free disk space for the replacement. RAM mode also holds the compressed rebuilt archive in memory and may not be faster. Automatic append can roll back after a caught write error, but cannot guarantee recovery from power loss or forced termination. Optional ZIP backups require space for a full copy of the original archive. Cancellation does not undo groups that have already completed.
