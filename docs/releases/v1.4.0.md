# BeamNG Info Config Generator v1.4.0

## Measure in game

- New **Measure in game** button reads real power, torque, peak RPM, weight, drivetrain, transmission, fuel, and induction of the selected configurations from BeamNG.drive itself, rounded like the game's own info files.
- The game starts with a temporary user folder that contains only a small measuring addon and the measured mods, then closes by itself. Installed mods, settings, and saves are not changed.
- Results open in the write preview, so every changed field can be reviewed before anything is written.

Checked against the stock ETK 800 on BeamNG.drive 0.40.3: power, torque, peak RPM, and powertrain matched the game's own file. Acceleration, top speed, and braking are not measured. See [Measuring in game](https://github.com/Holorigg/beamng-info-config-generator/blob/v1.4.0/docs/USAGE.md#measuring-in-game).
