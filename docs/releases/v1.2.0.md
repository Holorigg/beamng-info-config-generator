# BeamNG Info Config Generator v1.2.0

## RLS Contracts

- New **RLS Contracts** window checks Drift, Drag, and Race eligibility by vehicle model, including pool membership, configuration types, and blacklists.
- Select models and apply a small, separate addon to extend the RLS contract pool. No rebuilding or editing of the RLS archive, vehicle mods, or career saves.
- Enable or disable the addon from the same window. Updates and enable/disable changes automatically create dated backups. Restart BeamNG after changes.
- Existing additions absent from a later scan are preserved. Multiple selected configurations of one vehicle become a single model entry.
- Other RLS versions are allowed after a compatibility warning, not blocked by version number.

Compatibility checks used **RLS Career Overhaul 2.7.2** files and its actual contract selector in an isolated Lua 5.1 environment. RLS still controls offer randomness, unlocks, ownership rules, and discipline filters. In 2.7.2, random Race offers require a configuration of type `Race`; simply adding a model does not bypass that filter. See [compatibility and verification](https://github.com/Holorigg/beamng-info-config-generator/blob/v1.2.0/docs/RLS_CONTRACTS.md) for details.
